# 🚀 Kai Flow Landing Page

Kai Flow için geliştirilmiş modern bir SaaS landing page projesidir.  
Demo talep formu, güçlü backend entegrasyonu ve conversion (dönüşüm) odaklı UI/UX tasarımı içerir.

---

## 📌 Proje Özeti

Bu proje, kullanıcıların demo talebi oluşturmasını sağlayan **full-stack bir landing page** uygulamasıdır.

Şunları içerir:
- ⚡ Performanslı frontend yapı
- 🔗 Stabil backend API
- 🧠 MongoDB veritabanı entegrasyonu
- 🎯 Dönüşüm odaklı kullanıcı arayüzü

Amaç:  
**Kullanıcıdan veri alma sürecini sorunsuz, hızlı ve profesyonel hale getirmek.**

---

## ✨ Özellikler

### 🎯 Demo Talep Sistemi
- Tam çalışan demo talep formu
- API üzerinden gerçek zamanlı veri gönderimi
- Backend validation (doğrulama)
- MongoDB’ye veri kaydetme
- Stabil request akışı (bağlantı kopma problemi yok)

---

### 🧠 Backend Geliştirmeleri
- MongoDB bağlantı optimizasyonu:
  - maxPoolSize / minPoolSize ayarlandı
- Otomatik yeniden bağlanma (reconnection) sistemi
- Gelişmiş hata yönetimi:
  - Network hataları yakalama
  - Detaylı loglama
- 503 hataları tamamen giderildi

---

### 🎨 UI / UX Geliştirmeleri

#### 🔥 Demo Butonu (Navbar + Hero)
- Gradient tasarım (mavi → mor → pembe)
- Glow (parlama) efekti
- Hover animasyonları (yukarı kalkma + ışık artışı)
- İki farklı kullanım:
  - Navbar → küçük ve kompakt (GitHub tarzı)
  - Hero → büyük CTA
- Responsive uyumlu

---

### 📋 Form UI İyileştirmeleri
- Modern input tasarımı
- İç içe scroll problemi kaldırıldı
- Modal deneyimi iyileştirildi
- Daha dengeli spacing ve okunabilirlik

---

### 🌍 Form Geliştirmeleri
- Ülke seçimi (geniş liste)
- Görsel tutarlılık artırıldı
- Checkbox alanları eklendi:
  - Kampanya ve yeniliklerden haberdar olma
  - KVKK onay metni

---

### 🔒 Güvenlik
- reCAPTCHA entegrasyonu (UI hazır)
- Güvenli form gönderimi
- Backend validation katmanı

---

## 🛠️ Kullanılan Teknolojiler

### Frontend
- React / Next.js
- Tailwind CSS
- Lucide Icons

### Backend
- Node.js / Express
- MongoDB (Mongoose)

### Diğer
- REST API mimarisi
- .env yapılandırması
